# 玻璃漫步主题

在「设置 → 外观 → 主题 → 玻璃漫步」选择。欢迎页显示磨砂玻璃后的行人与猫影，工作页面沿用灰白玻璃材质。

## 完全本地运行

从 2026-11-19 起，运行时不再请求 `cellmotion.cn`，也不再使用远程播放器、编辑器页面或 iframe 桥接。

- `public/vendor/cellmotion/glasswalkers-renderer.js`：原版渲染器的本地快照（约 26 KB），源码、来源和校验值见同目录 README。
- `src/components/layout/glass-walkers-manifest.json`：保留场景、画幅、速度等配置；`runtime` 指向本地画布脚本。
- `public/images/glass-walkers-poster.png`：从相同场景参数在第 3 秒截取的本地静态首帧。
- `GlassWalkersBackground.tsx`：加载本地脚本，将场景配置传给原版 `draw(canvas, scene, seconds)`，管理时间、可见性和资源释放。

着色器源码和程序化纹理均在渲染器中，不需要外部字体、图片、脚本或在线服务。Vite 将 `public` 内容复制进 `dist`，Tauri 随应用打包这些文件，首次使用也不需要下载。

画布沿用原版预览的 1100px 最大渲染宽度及 1920 × 1080 比例，与静态首帧按相同规则 cover 主区域。人物比例、配色与其他场景参数不变。

## 加载与生命周期

选中主题时提前加载本地渲染器，在设置页也会初始化第 3 秒的静止画面。进入欢迎页后播放；离开欢迎页或隐藏窗口时取消动画帧，返回时复用同一画布与 WebGL 上下文，继续播放。

初始化期间先显示本地静态首帧，首次绘制完成后用 350ms 渐显接管。系统减少动态效果时停在第 3 秒并关闭过渡。脚本加载失败、绘制失败或 WebGL2 不可用时保留静态画面；WebGL 上下文丢失时也回退至静态画面。

切换到其他主题或卸载应用时取消动画帧、移除监听器和画布，并通过 `WEBGL_lose_context` 释放 GPU 上下文。保留的是已加载的脚本定义，不是后台持续播放的动画。

## 验证与限制

- TypeScript 与 Vite 生产构建。
- Chromium 使用真实本地渲染器，拦截全部外部 HTTP 请求；验证没有外部请求和 iframe，初始化、播放、暂停、返回复用均正常。
- 验证静态首帧、减少动态效果、主题切换释放画布、WebGL2 不可用时回退。
- 静态首帧和实际动画截图自查。
- 原生 Tauri WebView 尚未复测；本地版已去掉原来跨域桥接及自定义协议来源检查的依赖。

## 工作页面材质

待办、定时任务、Agent Teams、设置及弹窗共享灰白底色、半透明面板和清晰中性边线，通过根节点 `data-app-theme` 限定范围。保留 Nova 原有字体、布局与任务状态色，悬停和选中使用灰阶底色，键盘焦点保留描边。切换其他主题后恢复对应材质。
